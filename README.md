# Dockerfile 解析与检查

带行号和多阶段上下文的 Dockerfile 静态分析。本地候选版 0.1.0，供比较和代码审查；尚未作为完整竞赛作品提交。

## 运行

安装 MoonBit 后在本目录执行：

```sh
moon check
moon test
moon run cmd/main
```

也可在本目录运行 `./verify.ps1` 验证本项目。`pkg.generated.mbti` 是真实工具链生成的公共 API。命名空间 `localreview` 仅用于本地，正式发布前应替换为申请人的账号。

## 本版范围

实现目标：逻辑行、指令、FROM 阶段和常见安全/可复现性诊断。

未承诺：完整 BuildKit heredoc、ShellCheck、完整 hadolint 规则集。

## 来源与实现方式

规格/算法参考：https://github.com/hadolint/hadolint。

## 审查

先看 `cmd/main/main.mbt` 的实际使用，再看公共 API 与测试文件。联网兼容性、性能数据或官方验收未执行的部分不得从本地单元测试成功推断。

## 下一阶段与明确限制

优先补 BuildKit heredoc、COPY flags + JSON 混用、Shell 语义和抑制注释；规则码借用 hadolint 命名，但不承诺与 hadolint 完全一致，DL3020 和 DL4006 目前是启发式建议。

本分装包自带 `web/index.html`（用 `start-review.ps1` 启动）。`cmd/web/main.mbt` 为薄适配层，网页调用编译后的真实 MoonBit 模块。

## 独立分装使用

本文件夹可以单独移动或建立仓库，不依赖其他候选项目。浏览器演示已编译，无须安装 MoonBit 即可试用（需要 Python 3）：

```powershell
./start-review.ps1
```

打开 http://127.0.0.1:8772/web/ 。修改和测试源码需安装 MoonBit 与 Node.js，再运行 `./verify.ps1`。本机尚未将 MoonBit 加入 PATH 时，可传入 `-MoonPath`。独立包不捆绑编译器。

仅含本项目源码和构建产物；没有上传仓库或发布包。`DUPLICATION.md`、`evidence/verification.json` 和 `MANIFEST.sha256.json` 提供查重、测试和完整性资料。
